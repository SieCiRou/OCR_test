# MLX90640 熱影像儀即時監控與分析系統

本專案基於 **MLX90640** 紅外線熱成像感測器，結合 **Python (Tkinter, OpenCV, Matplotlib)** 開發，打造一個具備即時熱成像、像素溫度打點、歷史溫度趨勢圖、資料記錄以及設備溫度校正與清晰度分析的桌面應用程式。

## 特點
- **嚴格校驗機制**：採用 `0x5A 0x5A 0x02 0x06` 幀頭比對與 16-bit Checksum 校驗，確保串口數據傳輸無誤。
- **斷線重連機制**：具備自動偵測並重新連接串列埠（COM Port）功能，提升工業環境部署的穩定性。
- **資料自動存檔**：支援即時將每一幀的環境溫度（TA）、最高/最低溫及 $32 \times 24$ 的全像素溫度自動持久化保存至本地（支援 CSV/Excel）。
- **進階 UI 介面**：整合大膽的高對比度主題（Tech Blue & Neon Yellow），改善數據可讀性。
- **清晰度辨識與溫度校正**：內建 Laplacian 影像邊緣計算，提供自動清晰度建議閾值與即時手動溫度校正（Calibration Offset）功能。

## 📂 檔案架構與演進

本專案包含兩個主要開發階段的程式腳本：

### 1. 基礎驗證版 (`Ttyping.py`)
* **核心目的**：實現感測器通訊與嚴格資料解析的基本架構。
* **主要特點**：
  * 使用嚴格模式（Strict Mode）驗證資料幀。
  * 支援將溫度數據輸出並串接儲存為 Excel 檔案 (`tempcopy_1009v2log.xlsx`)。
  * 基礎的 Tkinter 直式佈局。

### 2. 優化升級版本 (`tran2HeatmapRecordV3.py`)  *推薦執行*
* **核心目的**：大幅度翻新 GUI 佈局與視覺體驗，並加入現場應用的實用功能。
* **主要特點**：
  * **主題視覺優化**：改用深底藍（`#3761C1`）搭配亮黃（`#EBE32E`）的高對比主題，圖表、狀態列全部經過美化。
  * **響應式網格佈局**：採用雙欄棋盤式（Grid）版面配置，左側顯示熱圖與校正輸入，右側提供具備水平/垂直滾動條的 $32 \times 24$ 像素細節網格。
  * **即時軟體校正**：可在介面中輸入真實參考溫度，動態計算系統補償值（`Calibration_offset`）。
  * **高效 CSV 儲存**：相較於 Excel 追寫，改用高效能 CSV 流式追加（Apend Mode），確保長時間錄製不卡頓。
  * **影像清晰度演算法**：整合動態 `blurry()` 計算，利用前 50 幀的歷史變異數自動產出最佳閾值提示。

## 🛠️ 技術規格與通訊協議

### 1. 硬體參數
* **解析度**：$32 \times 24$ 像素（共 768 點）
* **鮑率 (Baud Rate)**：`115200`
* **通訊格式**：8 Data bits, 1 Stop bit, No Parity
* **自動輸出指令**：`0xA5 0x35 0x02 0xDC`
